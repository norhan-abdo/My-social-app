# 🚀 Social App

A responsive Social Media Web App built with React that simulates a basic social platform with authentication flow.

---

## 🔴 Live Demo
👉 https://tiny-crepe-ca037e.netlify.app/

---

## 🎯 Key Highlights
- Real-world social media features
- Full authentication flow
- CRUD operations for posts and comments

## ✨ Features

### 🔐 Authentication
- User Signup
- User Login
- Change Password

### 📝 Posts Management
- Create new posts
- Edit existing posts
- Delete posts
- Display posts feed

### 💬 Comments System
- Add comments
- Edit comments
- Delete comments

### ⚙️ Other Features
- Protected routes
- Form validation
- API integration
- Responsive UI design
---

## 🛠️ Tech Stack
- React
- JavaScript (ES6+)
- CSS
- REST API
- Netlify (Deployment)
